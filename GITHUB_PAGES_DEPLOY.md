# Nexora GitHub Pages Deploy

This project is ready for GitHub Pages.

## Publish

1. Create a public GitHub repository named `nexora-ai`.
2. Upload or push this whole `Nexora ai` folder.
3. In GitHub, open the repository settings.
4. Go to **Pages**.
5. Set source to **Deploy from a branch**.
6. Choose branch `main` and folder `/docs`.
7. Save.

Your website will be:

```text
https://YOUR_GITHUB_USERNAME.github.io/nexora-ai/
```

## Important

GitHub Pages hosts only the frontend. For the AI chat to work, keep the backend running locally:

```text
http://127.0.0.1:8000
```

The frontend already points to that backend.
