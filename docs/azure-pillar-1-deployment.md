# Azure Pillar 1 Deployment

Status: prepared but not approved. No command in this document has been run to create Software resources.

## Required environment values

GitHub variables: `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, `AZURE_SUBSCRIPTION_ID`, `AZURE_DEPLOYER_PRINCIPAL_ID`, and only after approval `AZURE_PILLAR1_LEAN_STAGING_APPROVED=true`.

GitHub `staging` environment secrets: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `DATABASE_URL`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, `NEXORA_AUTH_SECRET`, and optional `POSTHOG_PROJECT_API_KEY`.

Runtime values generated by Bicep: managed-identity client IDs, Service Bus namespace/queue, Blob account URL, exact CORS origins, expected Front Door ID, app version, Git SHA, and build timestamp.

## Approved deployment sequence

1. Receive the exact approval sentence from the final report.
2. Complete `github-azure-oidc-setup.md` and protect the `staging` GitHub Environment.
3. Set the approval variable only after cost and what-if review.
4. Manually dispatch `Azure Pillar 1 Staging` with `deploy=true`.
5. CI runs all tests and builds both Docker images.
6. OIDC logs into the currently selected subscription without a client secret.
7. Bicep validation runs again.
8. The foundation deploys, then API/worker images are pushed to separate ACR repositories with the Git SHA tag.
9. API, worker, Front Door Standard, custom WAF, and Static Web Apps deploy. APIM remains disabled.
10. Front Door ID/hostname are fed back into Container Apps origin validation and exact CORS.
11. The frontend deploys and the request/queue/worker/blob smoke test runs.

Render, production DNS, Nexora, and Supabase are not deployment targets.

## Rollback

Route traffic back to the last healthy Container Apps API revision, set worker max replicas to zero if processing must pause, or disable only the Front Door API route. Preserve the Service Bus queue, dead-letter queue, Blob data, storage account, managed disks, and Render fallback. Do not delete persistent data during ordinary rollback.
