Software SDK Dashboard

Install first. Sign in only when cloud features need it.

The Software SDK is public documentation and public package installation. Local validation, planning, dry-runs, and sandbox workflow tests do not require a Nexora account.

Install Without Login

Python 
pip install software-sdk
JavaScript 
npm install software-sdk

Docs, examples, downloads, and install commands stay public.

Public Local Mode

No account required
  • Run local validation
  • Create local plans
  • Use dry-run examples
  • Test sandbox workflows
Python example 
from software_sdk import ReliabilityMonitor

sdk = ReliabilityMonitor(project_name="local-agent")
plan = sdk.create_local_plan("Validate a workflow")
result = sdk.dry_run_workflow("sandbox", plan["steps"])

Authenticated Cloud Mode

Login or API key required
