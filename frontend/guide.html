What it does

Software is for AI-agent reliability.

Software measures, predicts, and improves how AI agents behave in real workflows. It collects telemetry, scores reliability, shows failures, tracks latency and tokens, and helps teams decide whether an agent is ready for production.

Purpose

AI-agent reliability monitoring

Collect workflow runs, model calls, tool calls, errors, retries, recovery attempts, and completion events from real AI systems.

How to use it

Start with this path.

This path moves from running the website to connecting a real project and checking whether your AI agent is behaving reliably.

/guideThis guidePictures, videos, and step-by-step instructions. /onboardingSetup wizardConnect, auto-detect, install, test, and verify. /dashboardDashboardKeys, projects, snippets, usage, and test events. /observabilityAI operationsRequests, traces, sessions, alerts, latency, errors, tokens. /codeCode pageDeveloper-focused coding and SDK information.

Run the local website

Start the FastAPI backend from the repository root. The backend serves the frontend pages directly.

python -m pip install -e . python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000

Open the Software guide

Use the guide page as the public explanation of what Software does and where each reliability screen lives.

http://127.0.0.1:8000/guide

Connect a project

Open the setup wizard, connect a project, choose a manifest, run the generated install, and prove the real protected path.

http://127.0.0.1:8000/onboarding

Watch account usage

Open the dashboard after creating a key and project. Use the generated snippet or the test event button to confirm data is arriving.

http://127.0.0.1:8000/dashboard

Debug AI operations

Open observability to inspect each AI request, trace, session, token count, latency value, error marker, and alert threshold.

http://127.0.0.1:8000/observability

Add SDK telemetry to an agent

Install the SDK locally and track workflow events from your own AI agent, then flush them into the Software dashboard.

pip install -e . python examples/custom_agent_example.py

What to check first

If the dashboard is empty, create an API key, connect a project, and send a test event from either the setup wizard or dashboard. If observability is empty, use the Send Demo Event button to make sample AI activity.
