Codex MCP block

The active local configuration for the 21st server.

C:\Users\user\.codex\config.toml 
[mcp_servers."21st"]
url = "https://21st.dev/api/mcp"
enabled = true

[mcp_servers."21st".env_http_headers]
"x-api-key" = "API_KEY_21ST"

Generated commands
